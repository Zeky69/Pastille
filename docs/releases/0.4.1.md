## Corrections

- **Codes de validation beaucoup plus fiables** : Pastille n'affiche plus un nombre quelconque dès qu'un mail ou un message parle de « code ». Le code doit maintenant se trouver juste à côté du mot qui l'annonce (« code », « OTP », « PIN », « vérification »…). Les années (« © 2026 »), les dates, les montants, les codes promo, les codes postaux, les numéros de commande, de facture ou de téléphone ne sont plus jamais pris pour un code.

## Mise à jour

Si Pastille est déjà installée, la mise à jour est proposée automatiquement : **Réglages › Général › Mises à jour › Installer**, ou depuis l'icône de la barre des menus. L'archive est vérifiée par signature avant l'installation.

## Nouvelle installation

1. Téléchargez **Pastille-0.4.1.zip** ci-dessous, ouvrez-le et glissez **Pastille** dans **Applications**.
2. Dans le Terminal, exécutez :
   ```
   xattr -dr com.apple.quarantine /Applications/Pastille.app
   ```
3. Lancez Pastille depuis Applications.

Configuration requise : MacBook à encoche (puce Apple), macOS 14 ou plus récent. Le fond Liquid Glass nécessite macOS 26.
