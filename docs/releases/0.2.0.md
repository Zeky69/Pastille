## Nouveautés

- **Annonce du morceau au choix** : une nouvelle option, **Réglages › Activités › Seulement quand je change de morceau**, affiche le titre uniquement lorsque vous passez au morceau suivant ou précédent (clavier, AirPods, application de musique). Le titre n'est plus annoncé quand une chanson s'enchaîne d'elle-même. L'option est désactivée par défaut.

## Mise à jour

Si Pastille 0.1.0 est installée, la mise à jour est proposée automatiquement : **Réglages › Général › Mises à jour › Installer**, ou depuis l'icône de la barre des menus. L'archive est vérifiée par signature avant l'installation.

## Nouvelle installation

1. Téléchargez **Pastille-0.2.0.zip** ci-dessous, ouvrez-le et glissez **Pastille** dans **Applications**.
2. Dans le Terminal, exécutez :
   ```
   xattr -dr com.apple.quarantine /Applications/Pastille.app
   ```
3. Lancez Pastille depuis Applications.

Configuration requise : MacBook à encoche (puce Apple), macOS 14 ou plus récent. Le fond Liquid Glass nécessite macOS 26.
